# CrumbSave v2

Вечерние сюрприз-наборы еды рядом с вами. Статический сайт (без сборки, без бэкенда) — работает на GitHub Pages.

## Что исправлено по сравнению с первой версией

| Проблема | Что сделано |
| --- | --- |
| Долгое открытие (бэкенд на Render засыпал, JS-бандл 580 КБ, фото с Unsplash) | Бэкенда нет вообще, страница отдаётся статикой с CDN GitHub. Нет тяжёлых картинок и шрифтов. Карта и QR-библиотека подгружаются только когда нужны. Список заведений кешируется на 10 минут. |
| Фейковые рестораны | Заведения берутся из OpenStreetMap (Overpass API) по реальным координатам пользователя. |
| Фейковые ссылки на 2ГИС | Ссылка — это поиск заведения по названию рядом с его точкой (`2gis.kz/search/<название>?m=lng,lat/17`), плюс ссылка на объект в OpenStreetMap. |
| «Рядом» не запрашивало геолокацию | Кнопка вызывает `navigator.geolocation`, обрабатывает отказ/таймаут/недоступность, сортирует по расстоянию, есть выбор радиуса 1–5 км. Если разрешение уже выдано — определяет место сразу. |
| Нет реального QR | QR генерируется в браузере: на экране оплаты (ссылка подтверждения заказа) и на билете (код выдачи `CRUMBSAVE|<заказ>|<PIN>`). |
| Оплата картой | Форма с проверкой номера (Luhn), срока и CVC. **Реальные платежи включаются ссылкой провайдера в `config.js`** (см. ниже). |

## Что здесь демонстрация

Заведения реальные, но **партнёрств с ними нет**: набор, цена и количество генерируются детерминированно по id заведения и везде помечены «демо-набор». Пока `paymentLinkBase` пуст, оплата идёт в тест-режиме и деньги не списываются. Не выдавайте демо-наборы за настоящие предложения заведений.

## Как включить реальную оплату картой

Сайт статический, поэтому деньги принимает провайдер, а не сайт. Создайте Payment Link у провайдера (Stripe, CloudPayments, Kaspi Pay и т. п.) и вставьте в `config.js`:

```js
window.CRUMBSAVE_CONFIG = { paymentLinkBase: 'https://buy.stripe.com/xxxxxxxx' };
```

К ссылке добавится `?client_reference_id=<номер заказа>`. Чтобы сайт узнавал об успешной оплате и гасил наборы, нужен серверный вебхук провайдера (отдельный маленький бэкенд) — в этой версии его нет.

## Запуск и тесты

```bash
python3 -m http.server 8000   # открыть http://localhost:8000
npm test                      # 12 тестов логики (Node 20+)
```

## Структура

- `index.html`, `css/style.css`, `config.js`
- `js/lib.js` — чистая логика (Overpass-запрос, классификация, расстояния, Luhn, заказы) — покрыта тестами
- `js/app.js` — интерфейс и роутер (`#/feed`, `#/map`, `#/place/…`, `#/checkout/…`, `#/ticket/…`, `#/orders`)
- `vendor/` — Leaflet 1.9.4 и qrcode-generator 1.4.4 (локально, без CDN)
