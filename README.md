# CrumbSave — Вечерние сюрприз-наборы еды в Алматы

Веб-приложение для спасения и покупки вечерних сюрприз-наборов свежей еды из пекарен, кафе и ресторанов Алматы со скидками до −70% с самовывозом.

## 🚀 Демо онлайн
Публичная версия доступна по ссылке GitHub Pages:
**https://abylau2.github.io/crumbsave/**

## 📱 Функционал
- **Экран 1: Геолокация и карта** — интерактивная карта Алматы (Достык / Абая) с пинами заведений и индикатором местоположения.
- **Экран 2: Каталог наборов** — лента с фильтрацией по категориям (Все, Выпечка, Готовая еда, Продукты), строка живого поиска и статус остатков.
- **Экран 3: Состояние отсутствия наборов** — пустое состояние с расширением радиуса до 8 км и push-уведомлениями.
- **Экран 4: Карточка товара** — детальное описание состава, аллергенов, времени самовывоза, рейтинга и правил бесплатной отмены.
- **Экран 5: Оформление заказа** — таймер удержания брони (05:00), выбор оплаты через Kaspi Pay, Apple Pay и банковскую карту с расчётом сервисного сбора (90 ₸).
- **Экран 6: Активный билет и выдача** — статус выдачи, динамический QR-код, резервный 4-значный PIN-код, навигация в 2GIS и интеграция с Apple Wallet.
- **Экран 7: Оценка и отзыв** — 5-звёздочная оценка, динамические контекстные теги и подсчёт сэкономленных средств.
